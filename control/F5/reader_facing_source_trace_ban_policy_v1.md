# reader_facing_source_trace_ban_policy_v1.md

## 1. 核心决定

从现在开始，论文正文中禁止出现任何“笔记痕迹、项目治理痕迹、对话痕迹、文件痕迹”。

尤其禁止：

- `в конспектах`
- `в записях`
- `в заметках`
- `по конспектам`
- `согласно конспектам`
- `в проектных файлах`
- `в F1 / F2 / F3 / F4`
- `в model contract`
- `в result contract`
- `в writing contract`
- `в коде`
- `в GitHub`
- `в clean run`
- `run_id`
- `Main`
- `d08`
- `d04`
- `rolling`
- `freeze`
- `данный файл`
- `этот проектный документ`

正文必须是 reader-facing dissertation，不是项目记录。

---

## 2. 正文中应如何替换

### 禁止写法

```text
В конспектах построение ERC связано...
```

### 正文替代

```text
Теоретическое построение ERC может быть связано...
```

或：

```text
Для построения ERC удобно рассмотреть...
```

或：

```text
Один из способов получить ERC состоит в минимизации...
```

---

### 禁止写法

```text
В конспектах возникает маршрут: сначала сделать градиентные шаги, затем использовать метод Ньютона.
```

### 正文替代

```text
С численной точки зрения естественна двухэтапная схема: сначала используются устойчивые градиентные шаги, затем применяется ньютоновское уточнение.
```

---

### 禁止写法

```text
Согласно F2 model contract...
```

### 正文替代

```text
В данной работе используется следующая расчетная постановка...
```

---

### 禁止写法

```text
В коде стратегия называется Main.
```

### 正文替代

```text
В эмпирической части основная стратегия называется моделью CtR–CtB.
```

仅在复现附录中，如确有必要，可写：

```text
В программной реализации модель CtR–CtB имеет техническую метку Main.
```

但正文禁止。

---

## 3. 允许出现“来源”的地方

以下位置可以出现来源痕迹：

1. 内部治理文件；
2. 冻结状态文件；
3. 写作策略文件；
4. 复现附录；
5. 程序 listing 附录；
6. 给导师或自己的说明文件。

但正式论文正文禁止。

---

## 4. 对已生成正文文件的修订要求

以下文件必须清理：

- `section_02_ctr_risk_budgeting_ru_v4_maintext_optimal.md`
- `appendix_ctr_erc_theoretical_derivation_ru_v1.md`

其中，正文第 2 章必须删除所有：

- `В конспектах`
- `из конспектов`
- `логика конспектов`
- `теоретическая конструкция из конспектов`

附录标题和正文也不应写“конспекты”，而应写成理论补充。

---

## 5. 新规则

从下一轮开始，所有正文输出必须通过以下检查：

1. 是否出现内部项目文件名？
2. 是否出现 F1/F2/F3/F4？
3. 是否出现 freeze/rolling？
4. 是否出现 GitHub/run_id/Main/d08/d04？
5. 是否出现“в конспектах/笔记中”？
6. 是否把理论来源痕迹转化成学术表述？

若出现，应先修正再输出。
